# **💎 Janitor AI Suite**

**В одной удобной кнопке.**  

Этот скрипт добавляет на сайт Janitor AI удобную панель, с помощью которой вы можете **сохранять свои переписки** и **скачивать открытые (только!) карточки персонажей** в один клик.

## **✨ Что он умеет?**

1. **Скачивать чаты:**  
   * 📄 **.TXT** — Обычный текстовый файл, чтобы читать переписку как книгу - откроется в любой читалке, для любителей иметь под рукой дорогое сердцу. Не содержит никакого кода, только отетки "You" и "Char" чтобы никто не заблудился при чтении.  
   * 🤖 **.JSONL** — Формат для **SillyTavern**. Позволяет перенести историю переписки в Таверну и продолжить общение там. Готов к импорту в СТ сразу после скачивания.
2. **Скачивать Персонажей:**  
   * 🖼️ **.PNG Карточка** — Скачивает полную карточку бота (с описанием, личностью, сценарием, примерами диалогов, тегами и первым сообщением) в формате V1 PNG. Важно: этот скрипт позволяет качать только ботов, описание которых авторы не прятали, иными словами он делает то, что вы можете сделать руками, но за секунду. После этого просто перетащите эту карточку в SillyTavern, и бот готов к работе\!
   *  🔥 **.JSON** - маленький файл для трекера ботов, облегчает заполнение формы.
3. **Удобство:**  
   * Работает на ПК и Android (через Kiwi Browser).  
   * Поддержка Русского и Английского языков.  
   * Никаких сложных настроек — установил и пользуйся.

Чтобы скрипт заработал, вашему браузеру нужен специальный помощник — расширение **Tampermonkey**.

* **Chrome / Yandex / Edge:** [Скачать Tampermonkey](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)  
* **Firefox:** [Скачать Tampermonkey](https://addons.mozilla.org/en-US/firefox/addon/tampermonkey/)  
* **Android:** Установите браузер **Kiwi Browser**, затем в нем установите Tampermonkey по ссылке для Chrome выше.  
* **iPhone (Safari):** Установите приложение **Userscripts** из AppStore.

## **🎮 Как пользоваться?**

1. Зайдите на сайт [janitorai.com](https://janitorai.com).  
2. Справа сверху вы увидите новую **темную панельку**.  
   * Вы можете перетаскивать её за заголовок, если она мешает.  
   * Кнопка − сворачивает панель в маленькую полоску.  
   * Кнопка RU / EN меняет язык.

### **Чтобы скачать переписку:**

1. Откройте любой чат с ботом.  
2. В панели появятся синие кнопки.  
3. Нажмите **Скачать .TXT** или **Скачать .JSONL**.  
4. Скрипт сам найдет всю историю (даже если она очень длинная) и сохранит файл.

https://github.com/user-attachments/assets/e1043ff1-ec29-4921-95b7-d7c173e9d9c2


### **Чтобы скачать персонажа:**

1. Откройте страницу профиля персонажа (или просто находитесь в чате с ним).  
2. Нажмите розовую кнопку **Скачать Карту (.png)**.  
3. Готово\! У вас есть PNG-файл с ботом.

## **❓ Частые вопросы (FAQ)**

В: Я нажимаю кнопку, а она пишет "Данные не найдены".  
О: Попробуйте просто обновить страницу (нажмите F5). Иногда скрипт запускается раньше, чем сайт успевает загрузить данные. После обновления всё заработает.  
В: Куда делся мой файл?  
О: Он скачался в папку "Загрузки" (Downloads) вашего браузера.  
В: Это безопасно? Мой аккаунт не украдут?  
О: Абсолютно безопасно. Скрипт работает только внутри вашего браузера. Он не отправляет ваши переписки или пароли третьим лицам. Он просто автоматизирует нажатия кнопок "Копировать" и "Вставить". Можно проверить сам скрипт через любой ИИ, как и файлы которые он скачивает. На видео так же показаны примеры.
